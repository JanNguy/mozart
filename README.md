# Mozart

> **En phase de développement.** Ce projet fait partie d'un ensemble de projets complémentaires que je publie sur mon GitHub: chacun apporte une brique à un écosystème plus large, et ils sont conçus pour fonctionner ensemble.

Mozart est un assistant en ligne de commande qui route automatiquement chaque requête vers le modèle d'IA le plus adapté. Il s'appuie sur Ollama pour les modèles locaux et utilise un modèle de classification entraîné localement (TensorFlow) pour identifier le type de la requête — code, mathématiques, RAG, conversation ou autre — avant de la transmettre au bon modèle.
